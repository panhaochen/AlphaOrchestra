# AlphaOrchestra 本地部署说明

本目录提供两条评审路径：

1. **离线审阅**：无需 API、Python 或项目依赖，直接查看随包提交的结果摘要、验证报告和典型运行产物。
2. **联网复现**：配置兼容 OpenAI 协议的模型 API 后，运行短期示例或完整实验。

## 一键入口

在项目根目录打开 PowerShell：

```powershell
powershell -ExecutionPolicy Bypass -File .\submission\06_本地部署\start_review.ps1
```

默认进入离线审阅，纯 PowerShell 即可运行。使用 `-Online` 可检查联网环境：

```powershell
powershell -ExecutionPolicy Bypass -File .\submission\06_本地部署\start_review.ps1 -Online
```

## 离线审阅内容

- `..\05_技术证据\00_证据索引.md`
- `..\05_技术证据\02_指标快照\主要结果.csv`
- `..\05_技术证据\03_验证报告\`
- `..\05_技术证据\01_运行产物\` 中的 manifest、signals、routing 和调用记录

离线审阅不会访问网络，也不会重新调用大模型。它会直接读取随包提交的 CSV 指标快照并显示主要结果。

## 联网复现环境

- Windows 10/11
- Conda 或 Miniconda
- Python 3.10
- 建议 16 GB 以上内存
- 稳定网络和兼容 OpenAI 协议的大模型 API

创建环境：

```powershell
conda create -n mass python=3.10 -y
conda activate mass
pip install pdm
pdm install
```

复制 `.env.example` 为 `.env`，按实际服务填写：

```text
MASS_LLM_BASE_URL=https://your-provider.example/v1
MASS_LLM_API_KEY=your-key
MASS_CHAT_MODEL=your-chat-model
MASS_REASONING_MODEL=your-reasoning-model
MASS_LLM_CACHE_MODE=readwrite
```

不要把真实密钥提交到压缩包或录入视频。

## 联网短期示例

确认环境变量已加载后，在项目根目录运行：

```powershell
python -m stock_disagreement.main --random_seed 42 --num_investor_type 16 --num_agents_per_investor 4 --stock_pool csi_300 --stock_num 50 --selected_stock_num 3 --start_date 20240102 --end_date 20240105 --evaluation_start_date 20240102 --no-use_agent_distribution_modification --use_heterogeneous_agent_pool --use_adaptive_router --router_top_k 0 --router_min_k 8 --router_max_k 24 --router_diversity_lambda 0.35 --router_cost_lambda 0.05 --router_exploration_lambda 0.2 --router_family_diversity_lambda 0.5 --use_disagreement_diagnosis --abstention_threshold 0.7 --profile_maturity_days 15 --use_contextual_aggregator --use_conditional_debate --max_debate_agents_per_stock 2 --max_debate_stocks_per_date 2 --max_agent_calls_per_date 24 --max_debate_calls_per_date 4 --max_tokens_per_date 500000 --signal_alpha 0.7 --signal_alpha_1d 0.7 --signal_alpha_5d 0.7 --signal_alpha_10d 0.7 --run_id reviewer_smoke_seed42
```

`MASS_LLM_CACHE_MODE=readwrite` 时，网络中断后重新运行同一命令可复用已完成请求。

## 目录说明

- `项目源码/`：项目运行所需代码副本。
- `示例数据说明.md`：数据范围、来源和限制。
- `start_review.ps1`：评审入口。
- `review_results.py`：离线结果摘要程序。
- `requirements_review.txt`：离线审阅的最小依赖。

完整 CSI300 数据位于项目源码中的 `stock_disagreement/dataset/`。免费数据来源及截至日期见数据目录中的 metadata 文件。

## 已知限制

- 联网复现的速度和稳定性取决于模型服务商。
- 免费数据不能替代商业点时数据库。
- 当前系统用于投研辅助、观点冲突分析和模拟跟踪，不构成投资建议。
