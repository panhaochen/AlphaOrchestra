## 3. 效率证据

- 2024Q2增强系统日均激活14.14/64个候选，较全量激活减少77.9%。
- 1,090条智能体记录成功率98.17%；总请求记录1,937条，其中缓存请求1,596条。
- 统计令牌总量6,176,360，计费令牌1,682,604。
- 网关货币费用字段为0，故材料不宣称已实测人民币/API金额节省。
- 相对“全量512智能体”只能给出激活数量的理论比例（14.14/512），不得表述为512智能体实测成本或效果对照。

原始聚合快照见 `02_指标快照/submission_evidence_snapshot.json`。

## 4. 表现不佳的案例与适用范围

1. 2026全期组合显著跑输基准；策略当前定位为辅助研究和信号生成，而非无人值守实盘系统。
2. 两个快速基准增强组合候选均未改善全期表现，已保留在源码测试和运行目录中，但不作为主结果。
3. 免费数据在历史成分、复权和基本面覆盖方面有限。
4. 64候选池不是原论文512智能体的等规模复现，不能声称“16/64智能体效果大于等于512智能体”。
5. 绝对收益、回撤和交易成本仍需在参数预先确定的更长独立样本、仿真盘与人工风控中继续检验。

## 5. 建议评审核查路径

1. 阅读 `03_验证报告/q2_blind_64_vs_4_acceptance.md`，核对主要对照结论。
2. 查看两组 `manifest.json`，确认日期、种子、候选规模与模块开关。
3. 用随包脚本读取 `signals.parquet`、`routing.parquet` 和 `llm_calls.parquet`，复算RankIC、激活率与成功率。
4. 查看前缀不变性PASSED记录和2026扩展报告，确认时序一致性及样本外适用范围。
5. 按`06_本地部署/部署说明.md`运行离线演示；如配置API密钥，可继续联网复现实验。
